# Project Guide

## 1. Purpose

Build a small Spring-like container from scratch while following a video
course. This is a learning project, so keep implementations simple and clear.

## 2. Structure

- `src/com/orca/spring/`: framework code.
- `src/com/orca/service/`: example application code.
- `docs/`: learning documentation.

## 3. Documentation

Keep documentation concise and follow this format:

- Leave only the document title unnumbered.
- Number headings as `1`, `2`, `3`, and subheadings as `1.1`, `1.2`, and so on.
- Put a table of contents after the title with links to every content heading.
